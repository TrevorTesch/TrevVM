# TrevVM (run this in codespaces)
## Installation
First start a new blank codespace by going to https://github.com/codespaces/ and choosing the "Blank" template. (YOU CAN ALSO MAKE A CODESPACE OFF THIS)
Then copy and paste this command in your codespace terminal and hit enter.
```
curl -O https://raw.githubusercontent.com/TrevorTesch/TrevVM/main/install.sh
chmod +x install.sh
./install.sh
```
<b>NOTE: YOU NEED TO ALSO RUN THIS AFTER THESE CMDS FROM ABOVE.</b>

```
docker build -t trevvm . --no-cache
```
